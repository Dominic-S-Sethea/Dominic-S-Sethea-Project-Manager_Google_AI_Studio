# Project Manager — Hand-Over Guide

> **Purpose:** Instructions for transferring Project Manager development from one chatbox to another.

---

## 1. When to Hand-Over

Hand-over is appropriate when:
- Planning is complete and implementation is starting
- A chatbox reaches a natural milestone (e.g., Phase 1 complete)
- The user requests a hand-over
- A new specialist/assignee is needed

---

## 2. Hand-Over Procedure

### Step 1: Finalize Current Work
- Complete all pending tasks
- Resolve or clearly document open items
- Verify all files are saved and up-to-date

### Step 2: Save Progress
- All files are persisted to disk (not only in memory)
- Key files to verify:
  - `memory.md` — project memory and context
  - `design-system.md` — UI/UX design system (36 sections, 47 KB)
  - `rules.md` — development rules and conventions
  - `hand-over-guide.md` — hand-over instructions
  - `hand-over-checklist.md` — verification checklist
  - `Project Manager.docx` — research paper (UI/UX discovery)

### Step 3: Create Hand-Over Summary
Prepare a concise summary including:
- Current phase and status
- Key decisions made
- Open items and pending questions
- Next steps

### Step 4: Notify Next Chatbox
- Provide the file location
- Specify what the receiving chatbox should verify
- Reference the hand-over checklist

### Step 5: Verify Durability
- Confirm files exist on disk
- Read back key files to verify content

---

## 3. Hand-Over Checklist

See: `hand-over-checklist.md`

## 4. Post-Hand-Over Verification

After hand-over, the receiving chatbox should:
1. Check that all files exist and are readable
2. Review the hand-over summary
3. Verify the open items are clearly documented
4. Confirm the next steps are clear
