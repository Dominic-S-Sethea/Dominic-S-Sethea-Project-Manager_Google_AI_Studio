# Project Manager — Hand-Over Checklist

> **Use this checklist before and after every hand-over to the next chatbox.**

---

## Pre-Hand-Over Checklist

### 1. Work Completion
- [ ] All pending tasks are completed or clearly documented
- [ ] All decisions are recorded in `memory.md`
- [ ] All open items have a designated owner and due date
- [ ] All files are saved to disk

### 2. File Verification
- [ ] `memory.md` exists and is up-to-date
- [ ] `design-system.md` exists (47 KB, 36 sections)
- [ ] `rules.md` exists and reflects current decisions
- [ ] `hand-over-guide.md` exists
- [ ] `Project Manager.docx` present (research paper)

### 3. Progress Review
- [ ] Current phase and status documented
- [ ] Next steps clearly identified
- [ ] Outstanding questions listed with context

### 4. Hand-Over Summary
- [ ] Summary is concise (what was done, what's next)
- [ ] Key decisions are recorded with rationale
- [ ] File locations are referenced

---

## Post-Hand-Over Checklist (Receiving Chatbox)

### 1. File Verification
- [ ] All files exist and are readable
- [ ] `memory.md` content reviewed
- [ ] `design-system.md` reviewed (key sections)
- [ ] `rules.md` reviewed (critical rules)

### 2. Context Review
- [ ] Project separation confirmed (CDES Student Instructor V1.2.0 is NOT to be modified)
- [ ] Current phase and status understood
- [ ] Open items and next steps understood

### 3. Communication
- [ ] Acknowledge hand-over
- [ ] Confirm or question the next steps
- [ ] Raise any concerns about the hand-over

---

## Common Completion Signs

### Phase 1: Core (Planning → MVP)
| Item | Status |
|---|---|
| Design system documented | ✓ Complete |
| Memory/context created | ✓ Complete |
| Hand-over guide | ✓ Complete |
| MVP feature freeze | ✓ Complete |
| MVP scope | ✓ Complete |

### MVP Feature Freeze (Minimum to Ship)
- Projects, Tasks, Checklists, Dependencies, Comments
- Online/offline sync, RBAC, Audit log
- Agent authentication, Human approval flow
- Multi-provider AI model selection, Export (JSON+CSV)
- Basic task list + dashboard

---

## Escalation During Hand-Over

| Issue | Action |
|---|---|
| Missing files | Report to sender |
| Unclear decisions | Ask for clarification |
| Security concerns | Escalate to owner immediately |
| Blocked / Time / Quality | Escalate to CEO with evidence |

---

## Notes

- All files must be verified as existing on disk
- The receiving chatbox should NOT assume work is done without verification
- Communication should be explicit and confirm understanding
